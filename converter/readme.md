# Конвертер значений
## 4 конвертера в оболочке терминала:
1. Километры в Мили
2. Милы в Километры
3. Градусы Цельсия в градусы Фаренгейта
4. Градусы Фаренгейта в градусы Цельсия

## Запуск
Скачать файл `main.py` из директории, открыть папку загрузок, открыть в этой директории командную строку и вписать `python main.py` или `python3 main.py`
