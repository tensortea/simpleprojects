# Сборник небольших, легких и банально простых проектов на базе языка **Python**
В каждой из директорий представлен файл `readme.md` с описанием каждого проекта и туториалу по его запуску в конце.  

## Проекты
1. **[Калькулятор](./calculator)** - простой консольный калькулятор с несколькими функциями
2. **[Угадай число](./guess_a_number)** - игра на угадывание числа за определенное количество попыток
3. **[Генератор пароля](./password_generator)** - генератор безопасных паролей заданной длины
4. **[Конвертер](./converter)** - конвертирует значения(например, Км в Мили, градусы Кельвина в Цельсии)
5. **[Виселица](./hangman)** - классическая игра виселица в консоли
6. **[Таймер](./timer)** - таймер с двумя режимами (к времени / через время) и звонком

## Начало работы
Клонируйте репозиторий:  
```bash
git clone https://github.com/tensortea/simpleprojects.git  
cd simpleprojects
```
### Обобщенный запуск всех проектов
Скачать файл main.py, открыть папку с файлом в командной строке(*cmd*) и вписать `python main.py` или `python3 main.py`. В некоторых проектах требуются дополнительные библиотеки(*playsound==1.2.2*), предоставленные в ***requirements.txt*** для установки через `pip install -r requirements.txt`
