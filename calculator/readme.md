# Калькулятор
**Калькулятор** в консоли с многими операциями между двух чисел
### Операции
*1. Сложить*  
*2. Отнять*  
*3. Умножить*  
*4. Разделить*  
*5. Возвести в степень*  
*6. Квадратный корень*  
#### А также функции тригонометрии:   
*1. Синус*  
*2. Косинус*  
*3. Тангенс*  
*4. Перевод радиан в градусы*  
*5. Перевод градусов в радианы*  
*6. АркСинус*  
*7. АркКосинус*  
*8. АркТангенс*  

## Запуск
Открытие cmd с установленным пайтоном в директории загрузки и вписать:  `python main.py`
