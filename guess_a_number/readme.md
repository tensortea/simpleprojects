# Guess the Number — English summary
A console game where you guess a number from 1 to 100 in 5 attempts. Hints "higher" or "lower" are given.

---

# Угадай число
Развлекательная игра в консоли, где необходимо угадать число от 1 до 100 за пять попыток. По мере игры есть подсказки >Больше или >Меньше
---




## Запуск
Скачать файл main.py, открыть папку с файлом в командной строке(*cmd*) и вписать `python main.py` или `python3 main.py`
