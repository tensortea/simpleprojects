# Сборник небольших, легких и банально простых проектов на базе языка **Python**
В каждой из директорий представлен файл `readme.md` с описанием каждого проекта и туториалу по его запуску в конце.

## Проекты
1. **Калькулятор** - простой консольный калькулятор с несколькими функциями
2. **Угадай число** - игра на угадывание числа за определенное количество попыток
3. **Генератор пароля** - генератор безопасных паролей заданной длины
4. **Конвертер** - конвертирует значения(например, Км в Мили, градусы Кельвина в Цельсии)
5. **Виселица** - классическая игра виселица в консоли
6. **Таймер** - таймер с двумя режимами (к времени / через время) и звонком

### Обобщенный запуск всех проектов
Скачать файл main.py, открыть папку с файлом в командной строке(*cmd*) и вписать `python main.py` или `python3 main.py`. В некоторых проектах требуются дополнительные библиотеки(*playsound==1.2.2, datetime*), предоставленные в ***requerments.txt*** для установки через `pip install requerments.txt`
