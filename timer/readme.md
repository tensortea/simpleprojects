# Timer — English summary
A console timer with two modes: set an alarm for a specific time, or set a countdown. Plays a sound when done.

---

# Таймер
Таймер с двумя режимами работы:
1. Звонок к определенному времени(как будильник)
2. Звонок через определенное время

### Реализация
Программа работает в консоли.

## Запуск
Скачать файл timer.py и alarm.mp3, открыть папку с файлом в командной строке(*cmd*) и вписать `python timer.py` или `python3 timer.py`. Установить библиотеки *requirements.txt* через `pip install requirements.txt`.
